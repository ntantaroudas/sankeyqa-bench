# SankeyQA data — artificial data

All data in this folder are **artificial**. The career cohorts, flow tables, career-map images and questions were
generated by `code/scripts/make_dataset.py` (seed 2026) only to demonstrate and test the technology described in the
accompanying article. They are not real careers, contain no personal data, do not come from any real career database, and
must not be used to draw conclusions about real roles, industries or people.

* `tables/<id>.json` flow table of each cohort (ground truth)
* `images/<style>/<id>.png` career maps, `default` for all 600 cohorts, eleven other styles for 60 test cohorts
* `questions.jsonl` 6,560 questions with exact answers, `splits.json`, `styles.json`, `stats.json`
