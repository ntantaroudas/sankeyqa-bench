# SankeyQA — can small vision-language models read career maps?

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23449063.svg)](https://doi.org/10.5281/zenodo.23449063)

SankeyQA is an open benchmark of career-map Sankey diagrams with questions whose answers are known exactly. It was built
to test, without any user study, whether the virtual assistant of the **XR-CareerAssist** platform (VOXReality,
Horizon Europe) should explain a career map by reading the **picture** with a vision-language model or by reading the
**table of numbers** behind it.

> **The data are artificial.** All career cohorts, maps and numbers were generated by a computer program only to
> demonstrate and test the technology. They are not real careers, contain no personal data, are not drawn from the
> CVCOSMOS database and must not be used to draw conclusions about real roles, industries or people.

* 600 artificial (simulated) career cohorts, 358 role maps and 242 industry maps
* 1,260 career-map images in 12 drawing styles, drawn in the layout of the XR-CareerAssist career maps
* 6,560 questions of 11 types, with exact answers computed from the flow tables
* 5 small open models and 2 baselines evaluated on 875 test questions, 11 drawing styles, 6 BLIP fine-tuning runs
* everything runs on a laptop processor (the study used 2 CPU cores, no GPU)

## Main results (875 test questions about 80 unseen maps)

| Reader | Correct (%) | 95% interval |
|---|---|---|
| Exact query on the flow table | 100.0 | 100.0 to 100.0 |
| Guess that never looks at the map | 40.5 | 37.4 to 43.5 |
| Qwen2.5-0.5B reading the table as text | 38.9 | 36.3 to 41.4 |
| SmolVLM-500M reading the picture | 30.1 | 27.1 to 33.1 |
| SmolVLM-256M reading the picture | 27.7 | 24.9 to 30.3 |
| Random choice among the possible answers | 17.9 | |
| MatCha-ChartQA reading the picture | 16.0 | 13.8 to 18.2 |
| BLIP-VQA reading the picture | 12.7 | 10.8 to 14.7 |
| BLIP-VQA fine-tuned on 400 maps | 55.5 | 53.1 to 58.0 |

Twenty maps chosen for diversity by k-means (45.3%) were no better than twenty random maps (43.9% to 45.7%, three
draws). The fine-tuned model lost 9.5 to 13.6 points with a transparent background, other text sizes or no title.
**Conclusion.** An assistant should answer from the data behind the map and use the map only to show the answer.

## Where the files are

This repository holds the code, the flow tables, the questions, every model reply, all result tables and the
figures (PNG, PDF, EPS). The 1,260 career-map images and the 600 dpi TIFF figures are in the Zenodo archive,
https://doi.org/10.5281/zenodo.23449063, and the images can also be regenerated byte for byte with
`python code/scripts/make_dataset.py --out data`.

## Folder map

```

                      scoring.py, models.py model adapters)

results/finetune_runs/*/train_info.json   training maps, settings and loss of every fine-tuning run

                      references.yaml, check_references.py, reference_check.md

```

## Reproduce

```bash
pip install -r requirements.txt
cd code
python scripts/make_dataset.py --out ../data            # about 7 minutes
python scripts/run_eval.py --reader exact --set main
python scripts/run_eval.py --reader smolvlm-256m --set main   # also smolvlm-500m, matcha-chartqa, blip-vqa,
python scripts/run_eval.py --reader table:qwen2.5-0.5b --set main   # and --set robust for the drawing styles
python scripts/finetune_blip.py --selection kmeans --n-images 20 --out ../results/finetune_runs/kmeans20
python scripts/run_eval.py --reader blip-ft:../results/finetune_runs/kmeans20 --set main --outset finetune
python scripts/analyze.py && python scripts/make_figures.py
cd .. && python paper/check_references.py && python paper/build_ore.py && python preprints/build_preprints.py
```

`code/scripts/queue_all.sh` runs every evaluation and fine-tuning run in order and can be restarted, as it skips
what is done. The model versions are in `results/model_versions.json`. The fine-tuned weights (about 1.5 GB each)
are not included and are recreated by `finetune_blip.py`.
