Table 7 and Figure 5 show how the answers changed when the same 20 test maps were drawn in other styles. BLIP-VQA before fine-tuning answered so few questions correctly that no style made a difference. SmolVLM-256M answered 34.1% of these questions correctly in the default style, and only larger text clearly lowered its accuracy, by 7.3 percentage points. Changing the width of the image made no difference to either model, because both shrink the image to a fixed size before reading it.

The model fine-tuned on 400 maps was the most sensitive, because it had learned the default style. It answered 55.5% correctly in the default style and lost 9.5 points with a transparent background, 13.6 points with smaller text, 11.8 points with larger text and 10.9 points without the title (Table 7). Most of these losses came from the question about the total number of profiles, which the fine-tuned model had learned to read from the title. It answered 95.0% of these questions correctly in the default style but only 10.0% with a transparent background, where the black title becomes invisible once the image is placed on a black background, and 5.0% with larger text or without the title (extended data, table `robustness_by_qtype`). A transparent background, the problem met in the XR-CareerAssist project [@tantaroudas2026ore], therefore matters for a model that was trained on white backgrounds, and a model fine-tuned on one style should be used only with that style.
