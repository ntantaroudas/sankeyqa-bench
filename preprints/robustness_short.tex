The drawing style mattered most for the fine-tuned model, which had learned the default style. BLIP-VQA fine-tuned on 400 maps answered 55.5\% of the 220 questions of the style test correctly in the default style and lost 9.5 percentage points with a transparent background, 13.6 with smaller text, 11.8 with larger text and 10.9 without the title, mostly because it could no longer read the total number of profiles in the title. SmolVLM-256M lost 7.3 points with larger text and was otherwise unaffected, and the width of the image made no difference to any model.
